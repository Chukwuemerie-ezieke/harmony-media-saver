# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x | Yes |

## Reporting a vulnerability

Email security concerns to Harmony Digital Consults Ltd through [https://www.harmonydigitalconsults.com.ng](https://www.harmonydigitalconsults.com.ng) or open a private GitHub security advisory on this repository.

Please do not file a public issue for a vulnerability that could help someone steal media they are not authorized to access, escalate extension privileges, or exfiltrate browsing data.

We aim to acknowledge valid reports within 7 days.
