# Install Harmony Media Saver

The extension is not on the Chrome Web Store yet. Install it unpacked from this repository.

## Download the code

1. Open [https://github.com/Chukwuemerie-ezieke/harmony-media-saver](https://github.com/Chukwuemerie-ezieke/harmony-media-saver)
2. Click the green **Code** button
3. Choose **Download ZIP**
4. Unzip the archive
5. Confirm the unzipped folder contains `manifest.json` at the top level. If GitHub wrapped it in `harmony-media-saver-main`, select that inner folder later.

Or clone it:

```bash
git clone https://github.com/Chukwuemerie-ezieke/harmony-media-saver.git
cd harmony-media-saver
```

## Load it in Chrome or Edge

1. Go to `chrome://extensions` in Chrome, or `edge://extensions` in Edge
2. Turn on **Developer mode**
3. Click **Load unpacked**
4. Select the folder that contains `manifest.json`
5. Confirm **Harmony Media Saver** appears and is enabled
6. Click the puzzle-piece icon and pin the extension

## First-run check

1. Open the extension **Options** page
2. Keep the default streaming-site blocklist unless you need to add a school portal exception
3. For HarmonyLearn or another LMS you operate, add that host to the allowlist to ignore unrelated sites

## Update

Download a fresh ZIP or run `git pull`, then click **Reload** on the extension card.

## Remove

On `chrome://extensions`, click **Remove**. Chrome deletes the extension's local settings and history.
