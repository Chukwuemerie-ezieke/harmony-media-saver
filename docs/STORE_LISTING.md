Use this copy if you later submit a public listing. Review current Chrome Web Store program policies before upload. Extensions that enable unauthorized downloading of streaming media are not allowed.

## Name

Harmony Media Saver

## Summary

Save direct audio and video files from pages you are authorized to use.

## Description

Harmony Media Saver helps teachers, school ICT teams, and content owners keep a local copy of media files that a website already exposes as a normal downloadable resource.

It looks for direct files such as MP4, WebM, MP3, and M4A, then hands the URL to Chrome's download manager.

This is not a YouTube downloader and it will not bypass DRM, logins, or commercial streaming protections.

## Single-purpose statement

The extension's single purpose is to detect direct media files on the current tab and download a user-selected file through the browser download manager.

## Permission justifications

- downloads: start the user-selected file download
- webRequest: detect media content types
- tabs: associate detections with the active tab
- storage: save settings and local history
- contextMenus: save from a media element or media link
- host permissions: observe media on pages the user opens
